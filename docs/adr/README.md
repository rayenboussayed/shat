# SHAT ADR index — spec v1.0-draft §14.1

All decisions worth revisiting live as ADRs here. Each ADR file follows
`docs/adr/adr-template.md` and records status, decision, consequences and
revisit trigger. The authoritative required-ADR list lives in
[required-adrs.md](required-adrs.md). ADR files for the required list land
as their subtasks progress (S2, S3, S13, S19).
