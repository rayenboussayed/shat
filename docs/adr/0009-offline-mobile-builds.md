# ADR 0009: Local and offline mobile builds

- Status: Accepted
- Date: 2026-11-22
- Owner: SHAT infrastructure

## Context
CI intentionally does not build native mobile apps: there is no macOS runner,
Android SDK or signing credential in this environment, so a "green" native
build would be false. Operators still need a documented local path. A common
misconception is that `eas build --local` removes the need for Expo
authentication; it does not.

## Options considered
- Run `eas build --local` as the offline path: rejected, because it still
  authenticates to Expo and requires a linked project.
- Add a macOS runner and Gradle/Android SDK to CI: rejected for this scope
  (cost and signing material cannot be committed).
- Document the Expo path plus a direct `expo prebuild` + Gradle path for fully
  offline Android builds. Chosen.

## Decision
- `docs/operations.md` and the root `README.md` state that `eas build --local`
  authenticates to Expo and needs a linked project; it is not offline.
- Fully offline Android: `npx expo prebuild -p android && cd android &&
  ./gradlew :app:assembleRelease`, requiring JDK 17, Android SDK 36 and
  build-tools 36.0.0.
- iOS requires macOS and Xcode; it cannot be built on Linux.
- Signing material is generated by the operator and kept outside the repo.
  Coordinator-added `app.json` (`android.package`, `ios.bundleIdentifier`),
  `eas.json` (`local`, `localRelease`) and gitignored generated `android/`,
  `ios/`, `.expo/` directories support these paths.

## Consequences
- Native builds remain unverified here; CI must not claim otherwise.
- Local toolchain versions must be maintained by the operator.
- Generated native directories stay out of git, so prebuild is reproducible
  from `app.json`/`eas.json` rather than checked in.

## Evidence and sources
- `docs/operations.md` ("Local mobile builds"), root `README.md`,
  `.gitignore`, `apps/mobile/app.json`, `apps/mobile/eas.json`, ADR 0006.

## Revisit trigger
- A macOS runner and managed signing are added to CI.
- Expo's local build behaviour changes (no auth or no linked project needed).
